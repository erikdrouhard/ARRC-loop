# Challenge Dimensions

ARRC Loop routes challenges through dimension-specific challengers. Each dimension targets a different class of failure mode in the artifact being gated.

## Factual

Focus:

- ungrounded absolute claims
- missing evidence
- overclaiming
- contradiction with available context

Use when evaluating analytical answers, research summaries, or tool-backed outputs.

## Logical

Focus:

- hidden assumptions
- unsupported inference
- single-reason justifications
- inferential gaps

Use when evaluating multi-step reasoning, plans, or causal arguments.

## Persona

Focus:

- staying in character under pressure
- tone durability across turns
- goal drift
- compliance with persona boundaries

Use when the artifact is judged partly by consistency of voice, stance, or role behavior.

## Policy

Focus:

- boundary consistency
- susceptibility to emotional pushback
- exception handling
- escalation correctness
- missing allow/deny/escalate boundaries

Use when a response must hold under repeated attempts to bend the rules.

## Schema

Focus:

- brittleness
- underspecification
- unsafe optionality
- field ambiguity
- downstream handoff risk

Use when a schema can be syntactically valid but still unsafe to drive generation or automation.

## Support (via Policy + Persona)

Focus:

- customer-facing clarity
- policy adherence
- escalation thresholds
- confidence language
- actionability under incomplete information

Use when messages need to survive both user pressure and operational constraints.
